# Contributing to SC Trading R&D

This project values evidence over cleverness.

Before adding or changing a strategy experiment:

1. Write the hypothesis in plain English.
2. Freeze the entry, invalidation, exit, sizing, and ambiguity rules.
3. Add or update tests for deterministic logic.
4. State market-data source and date range.
5. State fees, spread, slippage, and fill assumptions.
6. Keep paper results separate from live results.
7. Never commit credentials or account data.

A profitable chart is not proof. A reproducible experiment is the minimum unit of research.
